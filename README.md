# 无限像素画布

一个零依赖、纯前端的网页像素画应用：**无限可拖动的画布，每个格子 = 1 像素，可缩放、可调画笔/橡皮大小、支持自定义笔刷、颜色代码显示、图片导入、透明背景导出、工程导入导出**。

## 使用方法

直接双击打开 `index.html` 即可（无需安装任何东西，建议 Chrome / Edge 等现代浏览器）。

## 代码结构

脚本按职责拆分为三个 JS 文件（在 `index.html` 中顺序加载，共享全局作用域，运行时不互相依赖加载顺序之外的条件）：

- **`pixel-canvas.js`**（约 2500 行）：像素画布核心——状态与数据模型、分块渲染、像素工具（画笔/橡皮/图形/填充/直线/统计/框选添加节点）、撤销重做、设置面板、自定义笔刷画板、图片与工程导入导出（PNG/JSON）、噪声生成、数学方程、主画布交互事件
- **`node-system.js`**（新增，约 700 行）：节点系统——对象模板 / 实例数据模型、节点类型注册表 `NODE_TYPES` 与扩展接口 `registerNodeType()`、基础节点（常量/输入/运算/动作）、节点图求值引擎（连线 DAG + 环保护）、实例渲染与 RAF 运行循环、节点编辑器 UI（节点画布/端口连线/全屏模式）；依赖 `pixel-canvas.js`，并约定「其他节点」目录下的插件 .js 在其后加载（见 `其他节点/wasd-move.js`）
- **`vector-canvas.js`**（约 550 行）：图层系统（新建/复制/删除/隐藏/重命名/添加节点按钮）、应用初始化；**矢量模式功能（矢量对象、矢量画笔、SVG 导出）已从界面移除，脚本保留**——恢复时在 `index.html` 加回「⬚ 像素画布」切换按钮与「✒ 导出 SVG」按钮（并取消 `vector-canvas.js` 中对应事件绑定的注释）

修改代码时注意：`node-system.js` 依赖 `pixel-canvas.js` 的 `state` / `els` / 渲染与撤销函数；`vector-canvas.js` 依赖两者，必须按 `pixel-canvas.js → node-system.js → vector-canvas.js` 顺序加载（`index.html` 中已是此顺序）。

## 工程文件格式

设置面板可切换导出格式（导入均自动识别）：

**v3 紧凑格式（默认，类似 pig2.json）**：

```json
{
  "app": "infinite-grid-canvas",
  "version": 3,
  "pal": ["#rrggbb", "#rrggbbaa", ...],
  "rows": [[y, [[x1, x2, 调色板索引], ...]], ...]
}
```

压缩时（压缩等级 ≥ 1）为 `{"app","version":3,"alg":"deflate"|"gzip","data":"<base64 压缩数据>"}`。

**v2 旧版兼容格式（类似 pig.json）**：`{"app","version":2,"pixels":[[x,y,"#rrggbb"],...]}` 明文数组，文件较大但人类可读、兼容旧版本。

## 笔刷文件格式

  "version": 1,
  "name": "自定义笔刷",
  "w": 16,
  "h": 16,
  "pixels": [[dx, dy, "#rrggbb"], ...]

## 技术说明

- 纯 HTML / CSS / JS 单文件，Canvas 2D 渲染，零依赖。
- 稀疏存储（`Map<"x,y", color>`），画布无限大，只记录画过的像素。
- **分块缓存渲染**：像素按 32×32 分块缓存成小画布，每帧的绘制次数从"像素数"降为"可见块数"——导入 4K 照片后平移/缩放依然流畅；新区域按帧预算渐进重建，不卡顿。
- **绘图快速模式**：按下绘制时只渲染网格、隐藏像素等内容，松手后完整渲染，大图下绘图顺滑。
- **分片导入/导出**：图片/工程导入按行分片（每帧 ≤16ms）写入，导出 PNG 分片完成，界面始终响应。
- 笔刷绘制按 Bresenham 直线插值，快速拖动不断线。

## 节点系统（游戏基础 · Blender 几何节点式）

- **对象** = 可复用的像素模板，来源两种：🔲 框选剪切（像素从图层移除，可撤销；框选后**自动选中**新对象）、图层面板 📦（图层像素快照，不剪切原图层）。**实例** = 对象在画布上的动态实体，**归属图层**（实例化到当前活动图层）：图层隐藏时实例停止并隐藏，删除图层连带删除其实例，⚙ 图标高亮表示该图层有实例。
- 实例化默认回到原位并**自动运行**；节点编辑器 ⏹ 停止 / ▶ 运行 控制全部实例。实例可删除（左侧实例列表 🗑，或画布上点击实例选中后点「🗑 删实例」）。
- **节点图（Blender 几何节点式）**：每个对象一张节点图 `graph:{ nodes, conns }`，节点有输入/输出端口（向量/数字两种类型），**拖动输出端口（黄色圆点）连线到输入端口（蓝色圆点）**组合数据流，每帧沿连线从输出向输入递归求值，最终由动作节点驱动实例；点 × 删节点、点连线删除、拖动节点布局。
- **节点画布可缩放/平移**：滚轮以鼠标为中心缩放（15%~400%），空白处拖动平移画布，节点与连线随画布一起缩放移动；面板下方 ＋/－/⟲ 按钮同样控制。
- **节点集（10 大分类）**——覆盖 Scratch 式六大类能力，且支持**执行流（Scratch 式顺序执行）**：
  - **执行流模型**：节点上有绿色**执行流连接点**（左侧入口 / 右侧出口），从**事件帽子节点**（当开始运行、当按下(键)时、当对象被点击时）开始，沿连线按顺序执行后续节点；未连接任何执行流时保持旧行为（每帧执行全部动作节点）
  - **事件**（黄）：当开始运行（每帧执行链）、当按下(键)时（按键瞬间触发一次）、当对象被点击时（实例被点击瞬间触发）
  - **运动**（蓝）：移动 N 步、左转/右转（方向角 st.dir）、x/y 坐标增加（节点上带可调数值，连线优先）、x/y 坐标设为、移到随机位置、面向角度、面向鼠标
  - **控制**（橙）：**重复执行**（循环体=右侧连出的链；左侧「次数」端口未连=无限，每帧执行一次）、**条件判断**（任一条件为真则执行右侧链；节点上「➕ 条件」可添加更多条件端口）、选择(如果/否则)、节流(每N帧)
  - **侦测**（青）：碰到边缘?、随机 概率%?、鼠标距离<N?、键盘按下?（输出 0/1，连到条件判断）
  - **运算**（绿）：向量运算（相加/相减/缩放/单位化/长度/限制长度）+ 数字运算（A+B/A−B/A×B/A÷B/随机数/比较/与或）
  - **变量**（橙红）：变量值 / 设置变量 / 变量增加——变量在编辑器**右下方**输入框创建（每个对象有自己的变量列表，**每个实例的值独立**，存于 `inst.st.vars`）
  - **自制**（粉）：外部插件节点（见下）
  - 常量、输入、动作：常量向量/数字、键盘输入、鼠标位置、自身位置、目标位置、随机向量、帧计数、移动、设置位置（动作类节点带执行流连接点）
- **节点默认停止**：实例化后需点击「▶ 运行全部」才执行节点指令；⏹ 停止全部立即停止。
- **组合示例（执行流）**：
  - 当开始运行 → 移动 / x 坐标增加：每帧持续移动
  - 当按下(空格)时 → 重复执行(3) → x 坐标增加：按一下空格连跳 3 格
  - 当对象被点击时 → 移到随机位置：点一下实例瞬移
  - 当开始运行 → 条件判断(碰到边缘?) → 面向鼠标 → 移动：碰边就朝鼠标走
  - 数据流组合（旧方式）仍可用：键盘输入 → 移动、目标位置 ⊖ 自身位置 → 向量单位化 → 向量缩放 → 移动
- **全屏模式（⛶ 放大）**：左上节点库（分类 + 节点按钮，点击即添加到画布）、中间大节点画布（同小面板支持缩放/平移）、**右上正方形舞台**（实时预览主画布；「舞台大小」调舞台边长，「网格大小」调预览倍率——放大看像素细节）、**右下对象与实例**（对象下拉选择 → ⬇ 实例化直接放到当前图层，实例列表点选/🗑 删除）+ 实例信息（位置/方向/变量）。
- **自制节点（node-ther.js）**：所有自制节点统一放在根目录 **`node-ther.js`**（index.html 只引用这一个文件）；以后新增自制节点直接在该文件末尾用 `registerNodeType(...)` 写即可，**无需改 index.html、无需新建文件**。node-ther.js 内置：WASD 移动、**网格基础能力节点**（格子读取、格子写入[可指定坐标/颜色]、邻域格子数、删除自身、创建实例）+ **数学增强**（逻辑非/取模/取整/绝对值/较小/较大/**数字加减 A+B / A-B**）。
- **五子棋示例**：根目录 **`五子棋示例.json`** 是一个用节点系统搭好的可玩五子棋工程（导入即可玩）：「棋盘」对象带 7 节点图——点击棋盘 → `格子写入` 在鼠标位置落子（颜色=回合变量 turn：0 黑 1 白）→ `设置变量` 翻转 turn，实现黑白交替落子（胜负判断暂未内置，可在节点编辑器中继续扩展）。
- **2D 射击游戏示例**：根目录 **`2d射击游戏.json`** 是用节点系统搭好的可玩射击游戏（导入 → 点「运行」）：**玩家**（12×12，WASD 移动，Space 发射）、**子弹**（1×1，向上飞行、命中敌人时删敌并自毁、出屏自毁）、**敌人**（2×2，玩家 10 格内自动靠近，碰到玩家（中心距离 <7）则玩家死亡 → **自动重置**：清空子弹、玩家回出生点、重生 4 个敌人）。全部行为由节点图实现（玩家 19 节点 / 子弹 15 节点 / 敌人 8 节点），配套新增节点：**创建指定对象**（发射/生成）、**删除对象实例**（清空敌人/子弹）、**比较运算 A&lt;B / A&gt;B / A=B**（距离判断）。
- **秒表示例**：根目录 **`秒表.json`** 是 00-99 的秒表工程（导入 → 点「运行」）：每秒 +1，两位数字从 0-9 数字对象显示（**数字像素取自 `json/0-9.json`**，导入时按列自动拆分为数字0-9 共 10 个对象）。容器「秒表」的 22 节点图：帧数÷60 取整 → mod 100 得到当前秒数 → 十位=÷10、个位=mod 10 → 秒数变化时**删除全部数字实例**（`删除对象实例` obj=-2，保留容器）→ 用**动态对象索引**（`创建指定对象` 的 objIn 端口）重建十位/个位数字实例。配套新增节点：**除法 A/B**（`numDiv`）、**创建指定对象**支持动态「对象索引」输入端口、**删除对象实例**支持 obj=-2（删除所有对象实例）与未连线默认触发。
- **图灵完备**：节点系统可模拟 Minsky 双计数器机（无界数字变量 = 计数器，变量增加(±1) = INC/DEC，条件判断 + 重复执行(无限) = 条件跳转与循环），**已达到图灵完备**；node-ther.js 补充的逻辑/整数运算与像素读写节点进一步补齐实用能力。
- **扩展新节点**：任意脚本中调用 `registerNodeType` 即可：

```js
registerNodeType('我的节点', {
  name: '显示名', category: '运算', desc: '说明',
  sockets: [ // 端口：dir='in' 输入 / 'out' 输出；type='vec' 向量或 'num' 数字
    { key: 'a', dir: 'in', type: 'vec', label: 'A' },
    { key: 'out', dir: 'out', type: 'vec', label: '结果' },
  ],
  params: [ // 参数：节点上显示编辑控件
    { key: 'v', label: '值', type: 'number', min: -100, max: 100, step: 1, def: 1 },
  ],
  // 数据节点（有输出端口）：返回 {x,y}（vec）或数字（num）
  value: function (inputs, inst, p, st) { return { x: p.v, y: 0 }; },
  // 动作节点（无输出端口）：每帧执行，改 inst.x / inst.y 移动对象
  run: function (inputs, inst, p, st) { inst.x += inputs.a ? inputs.a.x : 0; },
});
```
