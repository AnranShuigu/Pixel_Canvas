# 无限像素画布

纯前端无限像素画布工具。双击 `index.html` 打开即可使用。

## 功能

- **绘画**：画笔（方块/自定义笔刷）、橡皮、大小/颜色调节、直线/矩形/圆形/三角形工具、填充
- **无限画布**：滚轮缩放、拖动平移、视图复位、背景网格
- **图层**：新建 / 复制 / 删除 / 隐藏 / 重命名
- **调色板**：20 个常用色、调色库（新建 / 重命名 / 删除 / 切换）、导入导出调色板
- **拾色器 / 噪声生成 / 数学方程**：更多工具菜单内
- **图片与工程**：导入图片、导出 PNG、导入导出 v2/v3 JSON 工程（可互导图片像素化、矢量画布）
- **矢量模式**：`vector-canvas.js` 提供矢量绘制能力
- **节点编辑器**（`node-system.js`）：对象 / 实例 / 节点图（数据流）编辑与运行，含声音、音乐编辑器节点

## 文件

- `index.html` — 页面结构 / 样式
- `pixel-canvas.js` — 核心逻辑（画布、图层、调色板、矢量模式）
- `node-system.js` — 节点系统（节点图求值引擎、节点编辑器）
- `vector-canvas.js` — 矢量绘制支持

## 导航

左上角标题可回到网页导航；顶部/右侧工具栏可独立隐藏（H 键隐藏界面）。
