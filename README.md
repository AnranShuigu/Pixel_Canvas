# 无限像素画布

纯前端「无限像素画布」工具：在无限大的网格上逐格绘制像素画，并内置**节点系统**（Scratch 积木 / Blender 几何节点式数据流）让像素「动起来」——可编程实例、声音、变量、事件驱动。

无需安装、无需联网、无需构建：双击 `index.html` 即可在浏览器中使用（或通过项目根目录 `一键启动.bat` 以本地服务方式打开，部分功能在 `file://` 下受限）。

## 绘画功能

- **画笔**（快捷键 `B`）：方块笔刷或自定义笔刷，大小 1–32 px
- **橡皮**（快捷键 `E`）：方块橡皮或自定义橡皮，大小 1–32 px
- **直线**：拖动绘制直线（Bresenham 算法，像素锐利）
- **封闭图形**：矩形 / 圆形 / 椭圆 / 三角形（拖动确定对角/外接框）
- **填充**：点击连通区域封闭填充（Flood Fill）
- **拾色器**：点击格子拾取颜色（矢量模式下可拾取矢量对象颜色）
- **颜色代码显示**：开启后鼠标所在格子显示红色选择网格 + 颜色代码与坐标

所有绘画操作均进入撤销栈（`Ctrl+Z` 撤销 / `Ctrl+Shift+Z`、`Ctrl+Y` 重做，默认 16 步，可在设置中调至 1–256 步）。

## 无限画布与视图

- **缩放**：滚轮（以鼠标为中心），范围 5% – 3200%（0.05× – 32×）
- **平移**：右键拖动，或按住空格 + 左键拖动
- **复位**：🔄 按钮回到 100% 缩放、原点居中
- **网格线**：可开关，间距「自动（随缩放）」或固定 1/2/4/8/16/32/64/128 px
- **坐标轴**：可开关；数学方程面板可显示数轴刻度数字（字号可调/自动）
- **触屏**：单指绘制，双指缩放/平移
- **性能**：画布按 32×32 区块分块缓存渲染，只重绘脏区块，支持超大像素量

## 生成器

「⋯ 更多工具」菜单中的四个程序化生成器（生成到屏幕中心，均支持撤销）：

### 🌊 噪声生成器
- 类型：Perlin / Simplex / Value / Worley 细胞 / Ridge 山脊
- 参数：宽高、X/Y 偏移、缩放、种子（🎲 随机，同种子同图案）、倍频（1–8 层细节）
- 模式：灰度 / 黑白二值（带阈值）/ 彩色渐变

### 🧱 纹理生成器
- 11 种纹理：砖墙 / 棋盘格 / 环境 / Gabor / IES / 迷幻 / 噪波 / 天空 / 沃罗诺伊 / 波浪 / 白噪波
- 参数：周期长/宽、生成大小、偏移、缩放、种子、倍频、双色 A/B

### ∑ 数学方程图像
- 支持 `y=f(x)` 显式方程与 `f(x,y)=0` 隐式方程（如 `x^2+y^2=16` 画圆）
- 函数：`sin cos tan sqrt abs log exp pow min max`；常量 `pi e`；运算符 `+ - * / ^ %`
- 参数：X/Y 范围、显示大小（1 数学单位 = N 像素）、采样步长
- 线条粗细 = 笔刷大小（主工具栏大小滑块控制）
- 可显示数轴刻度数字

### 🔳 二维码 / 条码生成器
- 二维码（QR）：byte 模式、版本 1–10、纠错等级 L/M/Q/H（含 Reed-Solomon、掩码、格式/版本信息）
- 条码：Code 39（支持 0-9、A-Z、`- . 空格 $ / + %`）
- 可设模块/高度、前景与背景颜色

## 图片导入与导出

**导入**（🖼 导入图片）：
- 静态图：PNG / JPG / WebP / GIF / BMP / TIFF 等，导入到当前图层、图片左上角置于屏幕中心；按行分片写入（每帧 24ms 预算）避免大图卡死；完全透明的像素自动跳过
- **动图**（GIF / APNG）：逐帧解码 → **每帧一个图层**（帧 0 替换当前图层），帧名 `图片·帧1`、`图片·帧2`…

**导出图片**（⬇ 导出图片，按钮右键或设置里切换格式）：
| 格式 | 说明 |
| --- | --- |
| PNG | 透明背景，静态 |
| JPG / JPEG | 有损压缩 |
| WebP | 可透明 |
| GIF | **动图**：每个可见图层 → 一帧（从下到上） |
| APNG | **动图**：每个可见图层 → 一帧（从下到上） |

GIF / APNG 编码器为纯 JS 零依赖实现（`image-codecs.js`），导出大小自动裁到内容边界并留 8px 透明边距。

## 工程导入导出

「导出工程 / 导入工程」支持三种格式（设置面板或按钮右键选择，导入自动识别）：

| 格式 | 特点 |
| --- | --- |
| **v5 全图层**（推荐） | 每图层独立 `pixels` 数组（含隐藏图层），导入逐层恢复，不合并、不损失各图层像素；矢量 shapes、节点对象/实例一并保存 |
| **v3 紧凑格式** | 调色板 + RLE 行段编码；可选 deflate/gzip 压缩（等级 0–10，在设置中调节） |
| **v2 旧版兼容** | `pixels` 明文数组 `[[x,y,color],...]`，兼容旧版工具（图片像素化、矢量画布等） |

工程文件还携带**节点系统的对象模板与实例**（含节点图 graph、变量 vars、实例状态 st），导入后完整恢复。导入时通过 `extra` 字段保留其他工具写入的扩展数据（如思维导图的 labels）。

## 矢量工具（✎ 右侧工具栏）

矢量形状与像素画共存于同一图层（`vector-shapes.js` 动态注入，不修改 index.html）：

- **入口**：点击 ✎ 进入矢量模式（默认矢量画笔，快捷键 `V`）；右键 ✎ 打开工具菜单（矢量画笔 / 贝塞尔 / 矢量框选 / 顶点编辑 / 矩形 / 椭圆 / 直线 / 三角形），再右键工具项可调出工具形式菜单或矢量绘制设置
- **设置**：⚙ 设置面板底部「✎ 矢量工具」区块，或工具菜单里右键任意工具项；含线宽（1–16 屏幕像素）、描边色、填充（开关/颜色/透明度）、吸附网格/顶点；💾 保存后写入 localStorage
- **线宽机制**：线宽为「屏幕像素恒定」（缩放时粗细不变）。**已选中形状时拖动线宽滑块即时生效**（可撤销）；未选中时仅影响之后绘制的形状
- 矢量形状可被框选建为节点对象（节点系统），也可随 v5 工程导出、被 v4 矢量工程格式互通

## 节点系统（核心特色）

像素画布不只是画图：可以把一块像素做成**对象**，添加行为节点，让它在画布上运动、交互、发声。

### 概念
- **对象（Object）**：一块像素模板（来自框选选区或整个图层），自带一张**节点图**
- **实例（Instance）**：对象放到画布上的一个「实体」，每个实例有独立的位置、变量、状态
- **节点图（Graph）**：数据流图——节点 + 连线，数据沿连线从输出端口流向输入端口，动作节点每帧驱动实例

### 创建流程
1. 用框选 `▢` 框住一块像素 → 节点编辑器 → `🔲 添加对象`（或图层右键 `📦 把此图层作为对象`）
2. 选中对象 → `⬇ 实例化` 放到当前图层
3. 在节点图上添加节点、连线 → `▶ 运行全部` 开始执行

### 节点分类（Scratch 配色）
| 分类 | 颜色 | 代表节点 |
| --- | --- | --- |
| 事件 | 黄 | 当开始运行 / 当按下键 / 当对象被点击 / 当条件成立 / 当收到消息 |
| 运动 | 蓝 | 移动 / 设定位置 / 移动步数 / 左转右转 / 改变 X/Y / 设为 X/Y / 随机位置 / 面向方向 / 面向鼠标 |
| 控制 | 橙 | 重复执行 / 如果那么 / 等待秒 / 限频 / 广播消息（等待） / 停止 |
| 侦测 | 绿 | 碰到边缘 / 鼠标接近 / 按键按下 / 随机布尔 / 计时器 |
| 运算 | 绿 | 向量加/减/缩放/归一/长度/钳制 / 随机向量 |
| 变量 | 橙 | 变量读取/设置/改变 / 数组读取/设置/长度 |
| 声音 | 紫 | 播放声音（等待）/ 停止全部 / 音量增减/设置 / 音调设置/增减 |
| 常量/输入 | 灰/蓝 | 常量向量/数字/字符串 / 键盘输入 / 鼠标位置 / 自身位置 / 目标位置 / 时间 |
| 自制 | 粉 | 内置在 `node-ther.js` 中的扩展节点（见下） |
| 插件 | 青 | 导入的外部 JS 插件节点 |

### 内置「自制」扩展节点（node-ther.js）
WASD 移动、读取/写入格子像素（pixelAt/pixelSet）、邻域格子计数、停止自身/全部、鼠标 X/Y、删除自身、创建/删除实例、自制节点模板、打印调试。

### 两种编辑器
- **面板模式**：节点编辑器小面板（对象/实例/节点图/变量/声音）
- **全屏模式**（⛶ 放大）：Scratch 式全屏编辑器——左侧节点分类与节点库、中间画布、右侧**舞台实时预览** + 对象/实例管理 + 实例信息面板；支持节点搜索、画布专注模式、舞台/分类/节点库宽度拖拽；节点编辑器与舞台还可**浮动成独立窗口**（⧉ 浮动，可拖动、可缩放）

### 编辑操作
- 左键框选多个节点 / 中键平移 / 滚轮缩放 / 单击选中
- 节点右键菜单：撤销/重做、复制/粘贴框选节点、打包为节点组、删除
- 端口连线：类型（vec 向量 / num 数字）必须一致；执行流为绿色 ◀▶ 连接点

## 自制节点与插件

系统以 **`registerNodeType('id', 定义)`** 为统一扩展接口，任何节点（内置/自制/插件）都通过它注册，注册后自动出现在编辑器分类/节点库中。

### 自制节点（🧩 自制）
- 点击「自制」按钮打开 JS 编辑器，直接编写 `registerNodeType(...)` 代码
- 语法高亮、错误提示、导入 js/txt、导出 js、删除节点
- `💾 保存` 后写入 localStorage，刷新页面仍保留；删除的内置节点也可被记住（重启不再出现）

### 插件（📂 导入插件）
- 导入外部 `.js` 插件文件（含 `registerNodeType`），导入后节点进入「插件」分类（插件库）
- 「🧩 自制插件」内置 5 个插件模板节点（综合模板 / 流程动作 / 数据 / 检测 / 参数+端口）
- 插件节点右键可随时编辑源码；`💾 保存` 永久保存，刷新后仍保留
- 插件帮助（?）与导入信息（📥）按钮可查看说明

### 节点定义字段速查
```js
registerNodeType('myNode', {
  name: '节点名', category: '自制', desc: '说明',
  flowIn: true, flowOut: true,        // 执行流连接点（绿色）
  displayVal: true,                   // 底部「值」显示框
  sockets: [{ key, dir:'in'|'out', type:'vec'|'num', label }],  // 端口
  params:  [{ key, label, type:'number'|'select'|'key'|'text'|'color', min,max,step,def }],
  value(inputs, inst, p, st) { … },   // 数据节点：返回 {x,y} 或数字
  run(inputs, inst, p, st) { … },     // 动作节点：每帧执行
});
```
- `inputs.端口key` 读连线值（未连线为 `null`）；`p.参数key` 读参数；`st.xxx` 是实例独立持久状态
- `inst.x / inst.y` 为实例左上角格子坐标，改它们即可移动实例
- 可访问全局：`state / keys / nextInstId / state.layers / state.instances / state.objects / requestRender()`

## 节点组 / 变量 / 数组 / 声音

- **节点组**：框选多个节点 → `📦 打包` 为可复用节点组（紫色节点）；双击展开编辑、子组可再打包、`🔄 解包`；节点组可导出/导入 JSON、保存到浏览器
- **变量**：每个实例独立的值（`➕ 建变量` 后用「变量」分类节点读写）；全屏编辑器变量区可保存
- **数组**：每个实例独立的数字数组（读取/设置/长度）
- **声音**：导入 mp3/wav/ogg 音频（或音乐编辑器导出的 JSON 工程，自动转码为 WAV），用「声音」分类节点播放；`🎹 音乐编辑器` 按钮可打开音乐编辑器（导出歌曲 JSON 后回来导入）；声音支持播放等待/音量/音调控制，隐藏图层时其实例声音一并停止

## 扩展接口（开发者）

- **注册节点**：`registerNodeType('id', def)` —— 全局函数，注册后自动进入编辑器
- **导入插件**：任何含 `registerNodeType` 的 JS 文件 → 节点编辑器插件库 `📂 导入插件`
- **自制节点持久化**：localStorage `nd-custom-nodes`（`{nodes:{id:code}, deleted:[...]}`）
- **调色板持久化**：localStorage `grid-palette-libs`
- **设置持久化**：localStorage（`btnSaveSettings` 保存：笔刷/橡皮/颜色/撤销步数/导出格式/网格等）
- **文件加载顺序**（index.html 已正确引用，勿改动顺序）：
  `image-codecs.js → pixel-canvas.js → texture.js → qr.js → node-system.js → node-ther.js → vector-canvas.js`

## 技术细节

- **零依赖**：全部代码为手写原生 JS + Canvas 2D，无任何第三方库、无构建步骤
- **数据模型**：像素存储为 `Map<"x,y", color>`，工程导出按行做 RLE 段编码 + 调色板索引
- **渲染性能**：32×32 区块分块缓存（`layerCache` / `layerChunks`），只重绘脏区块；撤销栈记录增量 diff 而非整幅快照
- **动图**：GIF（GIF89a + LZW）/ APNG 纯 JS 编解码，导入导出双向支持
- **QR 码**：GF(256) 有限域 + Reed-Solomon 纠错、掩码、格式/版本信息全部手写
- **节点引擎**：数据流求值（值缓存、环形依赖检测）+ 每帧动作执行 + 事件分发（按键/点击/消息/条件）
